## PRD

## 목표 
### **인증**

- 로그인에 성공하면 `{ "access_token": "..." }`를 반환합니다.
- 인증이 필요한 요청은 `Authorization: Bearer <token>` 헤더를 사용합니다.
- 토큰 만료 시간은 자유(예: 1시간)이며, Refresh Token은 구현하지 않아도 됩니다.

### **테스트 (필수)**

- CRITICAL: 아래 4가지 시나리오를 테스트 코드로 작성해야 한다(필수)

1. 회원가입 → 로그인 → 발급받은 토큰으로 `/users/me` 조회 성공
2. TODO 생성 → 목록 조회 → 수정 → 삭제
3. 토큰 없이 요청하면 401
4. 존재하지 않는 TODO ID로 요청하면 404
